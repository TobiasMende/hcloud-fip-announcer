# Security policy

Please report vulnerabilities privately through GitHub security advisories:
<https://github.com/TobiasMende/hcloud-fip-announcer/security/advisories/new>.
Do not open a public issue for a vulnerability.

Include the affected version, what you found, and how to reproduce it. You
will get a first answer within a few days. Fixes go into the latest release;
the project is v0.x and only the latest release is supported.

Notes on the Hetzner token scope are in [docs/security.md](docs/security.md).
